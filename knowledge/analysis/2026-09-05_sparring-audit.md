## 読んで分かったこと（この表の主目的。仮説の材料）

**1. 「世話を切らさない」は勝因ではない。** 強帯 9 体は全員 unfed>0 が 3-10 日・uncared>0 が 1-10 日ある。
それでも $133-190k。こちらは gen0018 以降 **unfed=0・uncared=0 を達成しているのに $74-104k**。
gen0022 で「uncared を 0 にする」ことに労働を割いた前提（EXP0022）は、
**勝ち筋そのものではなく、拡張を成立させるための必要条件だった**と読み直すべき。
→ 完璧な世話に労働を使い切るより、多少落としてでも規模を取る配分がありうる。

**2. move% はこちらの方が高い（悪い）。** 強帯は 44-54%、gen0022/0023 は **65%**、gen0013/0018 は 74%。
ゾーン化で 76% → 65% まで下げたが、**まだ強帯より 15-20 ポイント悪い**。
同じ hands 数でも実効行動数が 1.3-1.5 倍違う。ここは構造改善の余地が残っている
（`knowledge/IDEA_POLICY.md` の「出してよい」4 番＝労働割当の構造変更）。

**3. hands は多いほど良くない。** 強帯は **10-12 hands で 12-17 頭**を回している。
gen0023 は 13 hands・12 頭で、**より多い人手でより少ない資産**を回している。
gen0023 が gen0022 に勝てなかった（CI が 0 をまたいだ）理由の候補。

**4. 資産（動物）の数がそのまま資金差になっている。** 強帯の動物 12-17 に対しこちらは 12。
上位 3 体（kaito 15 / pilkwang 14 / yhay81 17）は動物が多い。
d15 の現金でも差が開く（強帯 $22-41k vs gen0022 $23k / gen0023 $16k）。

**5. gen0023 は gen0022 より d15/d20 の現金が低い。** $23.5k→$15.9k / $45.2k→$33.9k。
3 枚目の土地（SW）に払った $2,000 と 13 人目の hand が、この 2 シードでは回収できていない。
seeds50 の CI が 0 をまたいだ結果と整合する。

## 次に試す候補（優先順）

1. **move% を強帯並み（50% 未満）に下げる**。ゾーン内の巡回順・ユニット単位のまとめ処理。
   効果は「同じ資産でより多くの行動」なので、規模拡大と独立に効く。
2. **動物を 12 → 14-16 に増やす**（強帯の modal）。ただし 1 の労働効率が先。
   順序を逆にすると gen0020/0021 の再演（維持できない拡張）になる。
3. **hands を増やさずに 3 枚目を活かす**（gen0023 の 13 hands を 12 に戻して再評価）。

いずれも `harness/audit_replay.py --targets` で d15/d20 の現金が上位曲線に近づくかで判定する。
**強帯資金（`gate.strong_money_delta_paired`）が動かなければ前進と数えない。**
