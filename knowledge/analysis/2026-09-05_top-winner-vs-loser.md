## Q1: 同カードで Jesse が $51k と $93k に割れた理由 = **100% 市場側（プレミアム価格の床落ち）。生産側の差はほぼゼロ。**

Jesse Bullard の2試合（相手はどちらも Crop Dusta）の**ビルドはほぼ同一**:
- 両試合とも d0=2牛2羊/5hands/ME12 WH7、NE d6、メロンIPO d10、SW d11。動物累計も 5-7牛/13-14羊で同水準。

差は資金曲線の**中盤以降**に出る（Jesse P1 の end-of-day money）:

| | d15 | d18 | d20 | d22 | d24 | d29(final) |
|---|---|---|---|---|---|---|
| ep105510725（$51k, 負け大差） | 27.5k | 40.0k | 41.5k | 42.0k | **42.8k** | 51.6k |
| ep105506513（$93k, 接戦） | 28.2k | 51.9k | 61.5k | 70.6k | **77.9k** | 93.1k |

**d19-d24 で $51k試合は資金がほぼ停滞（+$1.4k / 5日）**、$93k試合は +$20k。原因は Jesse の1日売却収益（quoted price × 個数）:
- $51k試合 d19-24 の売却収益: **81 / 75 / 87 / 66 / 78 / 75**（＝ほぼ床$1）
- $93k試合 d19-24: **676 / 395 / 326 / 324 / 315 / 363**

決定的証拠は **MILK と WOOL の quoted price**:
- **$51k試合**: MILK d11=76 → d13=42 → d15=5 → **d16=1（以後 d29 まで$1固定）**。WOOL d18=125→d19=37→**d22=1**。STRAWBERRY **d20=1**。→ 3プレミアム品が d16-20 で床に落ち、そのまま回復せず（暴落は回復しないという価格関数の性質）。
- **$93k試合**: MILK は d20=68 / d25=68 / **d29=47**（一度も床に落ちない）。WOOL d24=179 まで高値。STRAWBERRY は d21=1 でも d28=59 に**回復**。

**結論**: Jesse は両試合で同じ量を同じ日に売っている（生産・売却タイミングは同一）が、$51k試合では相手と自分の乳・毛・イチゴが**町の吸収量（＝店抽選）を超えて床に落ちた**。差は農場でも売り時でもなく、**その品目を買い支える店がシーズンに開いたか否か**（→ Q3）。

**Jesse の唯一の可制御ミス**: 床（$1）に落ちた後も MILK/WOOL/ST を 1個/日 売り続けた（$51k試合 d16-27）。scout §4 の通り $1売却は在庫に戻らず**純損**。gen0020 は「quoted price が床閾値（例: base の 20%）未満なら当該品を売らず保留 or 別品目へ」というゲートを持つべき。

## Q3: 高額戦（$129-140k）と中額戦（$51-93k）を分けた要因 = **店抽選（プレミアム消費店の数）。上位は牛/羊比をその抽選に分岐させている。**

### (a) シーズンの天井は「プレミアム消費店が何軒開くか」で決まる（外生）
2試合の店抽選（同カード Crop Dusta vs Jesse）:
- **ep105510725（$71k/$51k, 中額）**: BAKERY×4 + YARN×1 + PET_CAFE×2 + BRUNCH×1。**乳消費店が PET_CAFE/BRUNCH の少数かつ登場が遅い（d9,d12）→ 乳が d16 に床**。小麦消費(BAKERY)ばかりで、飼料小麦は安いが乳・毛の穴が浅い。
- **ep105506513（$97k/$93k, 高額）**: YARN×2 + PIZZA + FARMERS + BAKERY + SMOOTHIE + ICE_CREAM + PET_CAFE。**乳消費店が4軒（PIZZA/SMOOTHIE/ICE_CREAM/PET_CAFE）→ 乳は最後まで $47-112、毛も YARN×2 で $200+ 維持**。

超高額戦（$129-140k）は乳・毛の穴が深いシーズンで、両者が市場を分け合っても床に届かない。中額戦はプレミアム消費店が薄いシーズン。**プレイの巧拙より抽選のほうが天井への寄与が大きい。**

### (b) 上位は d3 の第1店で牛/羊比を分岐する（可制御・最重要の未実装点）
keiz の3試合で**動物の追加スケジュールが第1店に連動**:

| ep | 第1店(d3) / 以降 | keiz の動物 |
|---|---|---|
| 105502808 | FARMERS_MARKET → YARN(d6) | **5牛11羊（羊寄せ）** |
| 105498461 | ICE_CREAM → BAKERY, BRUNCH | **9牛4羊（牛寄せ）** |
| 105444785 | ICE_CREAM → PIZZA, PIZZA | **14牛4羊（牛寄せ）** |

**d0-d2 は中立の 2牛2羊+小牛で固定 → d3 で第1店が判明 → d6-d11 の追加を「乳消費店(ICE_CREAM/PIZZA/BRUNCH/PET_CAFE)なら牛、YARN/FARMERS なら羊」に振る。**
これは tetsutani/prvsiyan の「店で特化」の実挙動。Giulio は常に牛寄せ(9牛5羊)、Syed/Yuan は羊寄せ(6牛11羊)固定＝分岐しないクローン。**分岐する keiz が LB 上位（Crop Dusta と接戦）。**

### (c) プレミアムが床のシーズンでの勝ち方 = 床が深い品への分散（同カード内 $20k 差の正体）
ep105510725（中額）で Crop Dusta が Jesse に $71k vs $51k で勝った差:
- Crop Dusta は **GOOSE 4羽（EGG）** を持ち、d21-28 に **CARROT を大量作付け**、d29 に CA23/EG11/ME11 を一括清算（最終売 rev $3,010）。
- Jesse は goose 0、carrot 少（最終売 rev $420）。
- **卵(床~3000)・ニンジン(床~500-850)・小麦(床~3000)は崩れない。** プレミアムが床に落ちたシーズンでは、崩れない品への転換が唯一の伸びしろ。実際 keiz/Giulio も d16+ に TOMATO/CARROT 種を追加している。

## gen0020 に効く発見トップ3

1. **d0 骨格は「2牛2羊・5hands・メロン種12・小麦種7」。土地 NE d6 / SW d11、hands 5→8(d6)→10(d8)→12(d11)、SEは買わない。** scout の「1牛4羊・メロン8・hands14」は実戦不一致なので実測値へ差し替える。

2. **牛/羊比を固定するな。d3 に開く第1店で分岐**（乳消費店=ICE_CREAM/PIZZA/BRUNCH/PET_CAFE → 牛寄せ、YARN/FARMERS → 羊寄せ）。d0-d2 は中立 2牛2羊で固定し、d6-d11 の追加分だけ振る。固定ビルドは乳店の薄いシーズン（=$51k試合）で乳が d16 に床落ちして停滞する。

3. **床落ち品を売り続けない＋崩れない品へ分散。** quoted price が base の ~20% 未満なら当該品の売却を停止（$1売却は純損）。d16+ に CARROT/TOMATO/EGG(goose) を積み、d29 は床の深い品（卵・ニンジン・小麦・メロン）で一括清算。プレミアムが床のシーズンでの同カード $20k 差はこれで説明できる。
