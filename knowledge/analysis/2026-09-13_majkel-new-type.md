## 4. 価格関数から見た市場構造（`kaggriculture.py:38-95`）

`price(inv) = base ± amp·f(|inv−I0|)`、`amp = target·base/f(T)`、`I0=10000`。**売ると在庫↑→価格↓、店消費（`_town_consume`）が在庫↓→価格回復。** 価格は「両者の供給」対「店抽選が決める消費」の瞬間バランスで決まる。

| 品目 | base | above_func / target / T | 性質 |
| --- | --- | --- | --- |
| 羊毛 | 200 | sq / 3.20 / 105 | 低volは緩、集中売りで急落（N=105 で床）。**YARN 消費が速いと戻る** |

**イチゴの price 差（G2: $166 vs $122）は「早撃ち＋トリクル」**。Majkel は d15 開始（1 日早い）で高値窓（$178-226）に 135個front-load、Mengfei は d22-24 に 92個dump して自分で $27 まで崩した。**同じ 243個でも先に高値窓を取った側が勝つ**（共有市場のレース）。

## 5. 判定 — denial 安全な非競合レバーはあるか

**無い。Majkel のエッジは共有・競合レバーの上手な運用＋店条件分岐で、非競合の新市場ではない。**

1. **羊毛/乳の高値は「店抽選が消費してくれる市場」を当てた結果**。羊毛が $222・床値0 なのは G1 が YARN 3軒を引いたから（消費が在庫を吸う）。これは shared §6（YARN 数→羊数）そのもの。**共有市場なので、我々が羊を増やせば相手の羊毛価格は下がる＝むしろ denial 陽性**だが、「誰も混まない新市場」ではない。
2. **イチゴのエッジは早撃ちレース**。先に高値窓を取るだけで、市場は依然として床落ちする（G2 d24 $27）。gen0051 終盤フラットライン解剖の「premium は共有市場で床に叩かれる」と矛盾せず、**それを補強する**（勝者は床落ち前に売り抜ける側）。
3. **卵（ガチョウ）だけが唯一の非競合市場**という 2026-09-10 の結論は変わらない。だが **新首位 Majkel は卵を一切使わずに勝っている**（G0 生涯）。卵を使うのはむしろ敗者 Mengfei（主流 B）で、$4-5k どまり。**卵は「加点」だが上位分離の源ではない**。

### 王者 gen0051 への含意（HANDOFF 3 原則との対応）
- **原理1（生産）**: Majkel の勝ち筋は「小麦スループット約2倍＋店条件に合った動物特化」。gen0051 は羊ピーク 4 固定・ガチョウ検討中で、**動物構成が店抽選に非応答**。ここが最大の構造ギャップ。
- **原理2（denial）**: 羊毛/乳/イチゴはすべて共有市場。**動物を店抽選に合わせて増やすのは denial 陽性**（相手の同品目価格を押し下げる）＝マージン定義に素直に効く。ただし読み違えると自分の供給過剰で自滅する（G2 の Mengfei）。
- **原理3（非競合＝卵）**: 既定路線の gen0055（ガチョウ）は正しいが、**上位分離の主因ではない**ことを新首位が実証。$4-5k の加点として位置づけ、期待を上振れさせない。

### 我々が採るべき順（この 2 本から。要 50seed 検証）
1. **店抽選条件の動物分岐**（羊 vs 牛のピークを YARN 数 / 乳消費店数で振り分ける）— 上位分離の主因。denial 陽性。shared §6 の観測が既に配線材料。
2. **メロン種を絞って小麦スループットへ資本移動**（ME を減らし d10 IPO を捨て d15 逆転を狙う）— 競合レバーだが上位の勝ち型。gen0051 の d10 現金は上位の 7%（gap_LATEST §2）で、そもそもメロン IPO で戦えていない。
3. **premium は「早撃ちトリクル」**（イチゴ・羊毛を高値窓で前倒しし床落ち前に抜く）— 売り方の competitive 改善。

## 学び（ゲーム構造への還元）
- **premium 市場の実現価格 = 両者供給 対 店抽選が決める消費**。engine の `_town_consume` は店ごとに固定品目の在庫を吸う（YARN→羊毛×2、SMOOTHIE→乳/イチゴ 等）。**「町が何を消費するか」に production を合わせた側が床落ちを免れる**。上位分離は「もっと作る/もっと高く売る」ではなく「**その試合の町が吸ってくれる品目に賭ける**」動的分岐で起きている。
- 卵が唯一の非競合出口という結論は不変。ただし**非競合出口は加点であって首位の条件ではない**。首位 Majkel は共有市場（羊毛・イチゴ・乳）を店条件で当てて勝っている。
- 「premium は床に叩かれる」（gen0051 endgame）は正しいが、**それは集中売りをした場合**。勝者は高値窓に front-load して床落ち前に抜ける（G2 イチゴ $166 vs $122）。トリクル×早撃ちは競合市場でも有効。
