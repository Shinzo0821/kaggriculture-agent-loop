# Stage B の自資金損失は「弱フィールドでの早期資本ロック」であって carrot 未換金ではない

- 日付: 2026-09-08（cycle6・opus）
- 対象: gen0049（Stage B 単独）・gen0050（FIX0020 単独）・gen0048（王者＝baseline）の 50seed 対応付き分解
- 出典データ: `records/eval_gen0049.json` / `eval_gen0050.json` / `eval_gen0048.json`（同一 pool・同一 seed）
- 手法: 3 ファイルの `games`（各 1100 対）を `(opponent, seed, cand_side)` で突き合わせ、対 gen0048 の
  **自資金差（cand_final 差）とマージン差（(cand−opp) 差）を相手別に平均**した。

## 結論（先に）

**「FIX0020（carrot 終盤清算）が Stage B を解錠する」（gen0051 の仮説）は、gen0051 の eval を待たずに
factorial の算術で反証される。** FIX0020 の相手別効果は**弱相手で +$116〜166**にすぎないのに、Stage B が
**弱相手で失う自資金は −$3,000〜3,451**。約 20 倍の桁差で、FIX0020 では埋まらない。Stage B の弱フィールド損は
**carrot 未換金ではなく、早期の資本ロック（SW 土地 d11→d8・イチゴ from_day 10→8 が d8 の再投資原資を奪う）**。

## 何が読めるか

1. **弱相手（starter・georgy）で Stage B は自資金もマージンも −$3.2〜3.5k と大きく負ける。**
   相手の稼ぎはほぼ動かず（マージン損 ≈ 自資金損）＝**こちらの生産が落ちている**。carrot 尻尾なら gen0050 が
   弱相手で同じ符号の損を出すはずだが、gen0050 は弱相手で**プラス**。よって Stage B の弱相手損は carrot 起因ではない。
   残る原因は Stage B が動かした 2 点＝**SW 土地購入 d11→d8（money=$437＝RESERVE 直上で買う）＋イチゴ from_day
   10→8**。市場競合の無い弱相手では早売りの価格優位が出ず、**早期の資本ロックが d8-13 の再投資を細らせた損だけが残る**。

2. **強帯ではマージン +$1,267（明確に正）。** 早売り＋denial が市場を食い合う強相手で効く（tetsutani/rayk/
   sokolovsky/boatlee16 で +$2k 級）。ただし kaito −$1,068・pilkwang は自資金 −$2,481 なのにマージン +$2,625 と
   **相手をより削って勝つ**型で、内訳は相手の骨格依存。**Stage B の価値は「強い相手＝共有市場の競合」に対してのみ本物。**

3. **gen0051 の加算予測**（factorial が加算なら）:
   - 全体マージン ≈ +130 +28 = **+$158**（CI は依然 0 をまたぐ＝検出不能・**gate.pass=False の公算大**）
   - 全体自資金 ≈ −556 +27 = **−$529**（依然点推定負）
   - 強帯マージン ≈ +1,267 −1.6 = **+$1,266**（依然明確に正）
   - carrot 増幅（7→18-21 枚）で FIX0020 の回収がやや効く**非加算性**はありうるが、gen0050 が示す通り
     回収額は市場深さに律速され強帯でフラット＝**弱相手の −$3.5k を埋める規模には全く届かない**。

## 帰結（cycle7-8 への申し送り）

- **gen0051 は「FIX0020 が Stage B を解錠する」筋では昇格しない見込み。** eval を読む時は上の予測と突き合わせ、
  外れたら（＝全体マージン CI 下限 > 0 なら）非加算の相互作用を精査する。予測どおりなら **CLOSED（検出不能）**。
- **Stage B の本質的な壁は「弱フィールドでの早期資本ロック」**。この型を LB に載せたいなら 2 択:
  - (a) **measure 提出**（強帯 +$1,267 は LB=強相手多数のフィールドで効く賭け。rating_delta 0 で要件 ≥−100 は満たす）。
    人の承認制。gen0049 は confounded として見送ったが、de-confound 済みの gen0051（or 弱損の主因が土地前倒しと
    確定すれば gen0049 でも可）を**強帯ベットの計測候補**として承認キューに積む選択はある。判断は gen0051 eval 後。
  - (b) **弱フィールドで資本ロックを起こさない Stage B 変種**（別系統）。early-sell の価格優位は強相手でしか出ない＝
    **土地前倒し/早植えを「共有市場の競合を検知した時だけ」条件発火**にする案。相手適応型は IDEA_POLICY で
    「相手型で作付けを切り替える案は別系統として可」（EXP0043）。実装・検証コスト高。跳躍候補ではない。
- **この分解自体が gen0027/gen0043 と同型の構造**: 強帯（LB proxy）に効くが弱・中で負けて全体ゲートが
  検出不能に沈む。ゲートは弱・中対戦が支配する。**「強帯だけ正」の型をどう扱うか**は繰り返し出る論点。
