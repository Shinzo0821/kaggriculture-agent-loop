# 強帯ルールの再検討 — 「点推定が正・CI が 0 をまたぐ」候補をどう扱うか（DIRECTIVES Q1 の材料）

- 日付: 2026-09-06 ／ 出所: `ops/NIGHTLY.md`「強帯（tier=strong）を見る義務」、`harness/evaluate.py` の `gate`
- 状態: **決着（2026-09-06）。人の判断は案 B。** `ops/NIGHTLY.md`「強帯を見る義務」と `CLAUDE.md` に反映済み。

## 1. いま何が起きているか（2 つのゲートがある）

| | 誰が判定するか | 条件 | 効果 |
| --- | --- | --- | --- |
| **昇格ゲート**（機械） | `harness/evaluate.py` の `gate.pass` | エラー 0 ／ `rating_delta ≥ 0` ／ **全体マージン差（対応付き）の CI 下限 > 0** | preflight が `--reason promote` を受理する条件 |
| **強帯ルール**（散文） | Supervisor が読んで判断 | 「**強帯資金が動かない改善は前進と数えない**」（`ops/NIGHTLY.md`） | `gate.pass` でも人（エージェント）が落とす |

**強帯は `gate.pass` に入っていない。** 機械ゲートを通った候補を、散文の規則が上から拒否できる構造になっている。

## 2. 規則の出自と、実際に起きたこと

- 出自: **gen0023**。全体 +$870 [−1,135, +2,874]（＝検出不能）で、**強帯は点推定 −$2,347** [−5,633, +940]。
  「弱い相手にだけ勝って強帯では負けている改善」を止めるために書いた。**この意図は正しい。**
- 適用の結果: **gen0027**（土地 SW を d11）が落ちた。50 シードで `gate.pass = True`、
  全体マージン **+$3,038 [+1,926, +4,150]**、自分の資金 +$2,615、**強帯は点推定 +$1,049**（CI [−322, +2,420]）。
  代わりに提出したのが **gen0031**（全体 +$538、自分の資金 **−$116**）。
- 後日: 同じ土地の変更を現王者の上で測り直した **gen0033** は、全体 **+$3,908 [+2,568, +5,248]**、
  **強帯 +$2,115 [+240, +3,990]** で強帯でも有意（`knowledge/experiments/EXP0033_land-sw-revisit.md`）。
  **土地の型は正しく、6 世代ぶん遅れた。**

## 3. なぜこうなるか（構造的な理由。運の問題ではない）

1. **強帯は標本が小さい。** プール 11 体のうち強帯は 8 体。同じシード数でも試合数が 8/11 に減るので
   CI は約 1.17 倍広い。効果量そのものも強帯では小さい（相手が強いほど差は圧縮される）。
   → **強帯に CI 下限 > 0 を要求するのは、昇格ゲートより厳しい基準**を暗黙に課すことになる。
2. **このリポジトリは既に「CI が 0 をまたいだ＝棄却ではなく検出不能」と決めている**（`ops/NIGHTLY.md` 検出限界）。
   強帯ルールだけがその原則を破って、検出不能を棄却として扱っていた。
3. 落とした側のコストは**見えない**。gen0027 を落としても記録には「非昇格」としか残らず、
   その型が正しかったことは 6 世代あとに偶然測り直すまで分からなかった。

## 4. 選択肢

| 案 | 規則 | gen0023 は | gen0027 は | 副作用 |
| --- | --- | --- | --- | --- |
| **A（現状維持）** | 強帯 CI 下限 > 0 でなければ前進と数えない | 落ちる ✓ | 落ちる ✗ | 検出不能を棄却として扱い続ける |
| **B（提案・推奨）** | **強帯マージンの点推定が負なら前進と数えない。**正で CI が 0 をまたぐなら「検出不能」として昇格ゲート（全体マージン）に従う | 落ちる ✓ | 通る ✓ | 真の効果 0 の候補が 5 割の確率で強帯フィルタを通る（ただし全体マージンの CI 下限 > 0 は満たしている） |
| **C（Bの慎重版）** | B に加えて、点推定が正で CI が 0 をまたぐ候補は**シードを増やして測り直してから**昇格 | 落ちる ✓ | 1 夜遅れて通る ✓ | 評価枠を 1 本余計に食う。締切まで 24 日なので毎回は回らない |

- B でも gen0023 は落ちる（強帯 −$2,347）。**規則を書いた本来の意図は B で保たれる。**
- 「強帯の点推定が負」で落とした候補は、**棄却ではなく「検出不能・要再測」として CLOSED.md の
  `再検討` に書く**（これは現行の規約どおり）。

## 5. 実装（案 B を採用した）

- `ops/NIGHTLY.md`「強帯（tier=strong）を見る義務」と `CLAUDE.md` の該当行を書き換えた。
- **判定量はマージンに統一した**（2026-09-06 codex レビュー P1-4）。旧文言は `strong_money_delta_paired`
  （自分の資金）を指していたが、全体の昇格ゲートは 2026-09-05 にマージン（自分 − 相手）へ移っている。
  gen0027 は強帯マージン **+$1,049** に対し強帯資金 **+$437** で別の数字であり、符号が割れた場合に
  読む人によって判断が変わる。資金と slope は診断用として残す。

  `gate` に符号を出す案が残っている。
- EXP テンプレの「判定」欄に**強帯の点推定と CI を必ず併記**（既に必須欄にある）。
