# EXP0017: shop-aware STR ピボット（メロン2波目の差し替え）

- 日付: 2026-09-04 ／ 世代: gen0017（親: gen0013）
- 仮説: LB 敗戦分析 cycle3-5 で3サイクル連続「敗因＝イチゴ(STR)不在」。STR 需要店（8型中4型、各6個/日恒久吸収）≥2 の抽選なら、メロン2波目を STR に差し替えれば需要に裏打ちされた d19-29 の収入傾きが立つ。
- 変更: `unlocked_shops` の STR 需要店 ≥2 で発動し、メロンタイルの空きに STRAWBERRY 植付（期限 d13）。d10-11 未発動は保留、d12 で <2 確定なら即メロン復帰（不発コスト最大2日遊休）。種購入・収穫・売却は既存体系に接続。
- 結果: vs gen0013 **34.0%**（Wilson [27.8, 40.8]、平均 **−$893**、200戦）／ vs starter 100%（平均 +$63,299）／ 400戦エラー0。提出ゲートは通過（王者≥30%）だが昇格ゲート不通過・絶対資金減。
- 判定: **棄却**（昇格せず。「ゲート通過+絶対資金増」の今夜の提出基準も満たさず提出見送り）
- 学び:
  1. **無肥料 STR はタイル単価でメロンに勝てない**: メロン 6個×base$250=$1,500/タイル vs STR 4個×$120-200=$480-800/タイル。干渉のない starter 戦でも絶対資金 −$2.4k（gen0013 比）で、局所ではメロン2波が単純に上。STR が逆転するのは (a) メロンが暴落する対戦（LB の両者供給・Avi 戦では STR $279 の希少高値）かつ (b) **肥料2倍化（当日肥料+水で 8個/タイル、FERTILIZE は day+2 まで有効 → age10 と age14 の2回で4収穫全部カバー、肥料2個/タイル）**を入れた時。肥料の機会費用は売値 $70-140/個 ≪ 追加ベリー $120-280/個 → **STR 系統の次レバーは肥料で確定**（gen0018）。
  2. 同時実施の LB 敗戦分析（cycle6, 5敗）で早期ゲート設計自体に反証: d9-12 で ≥2 になるのは 5戦中1戦のみ、しかし**終了時は5戦全てで ≥2**（4/8型×8抽選、P≈96.5%）。ゲートは機会損失側に倒れている → 基礎ブロックはほぼ無条件で植え、高需要抽選（Avi 型）で増量が正着。
  3. wave-1 メロンは資金バッファの階段状植付で実測 4タイル程度（seed7）。STR ブロックも同数に縮む → 「7タイル」の想定より効果が小さい。規模は wave-1 の設計とセット。
  4. **STR 単独では LB の実差 $27-45k を埋められない**（埋まるのは $8-15k）。cycle6 分析の根本敗因は「ビルド凍結」（土地0・hands 8止まり・畜産固定 vs 勝者の土地1-3枚・hands 9-13・主エンジン10-24規模）。勝ちエンジンは抽選次第で CARROT（Pet Cafe 2x）・WOOL（Yarn 2x）にもなる → 「STR 限定」でなく **unlocked_shops で需要口数最大の品目へ資本を寄せる汎用ピボット**への一般化が中期課題。
