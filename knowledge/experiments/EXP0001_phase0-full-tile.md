# EXP0001: Phase 0 全タイル稼働ルールベース

- 日付: 2026-08-30 ／ 世代: gen0001（親: なし、初代）
- 仮説: starter は farmer 1体・1タイルのニンジンループなので、NW 25タイル全稼働（小麦/ニンジン混作、座標偶奇で固定割当）+ ハンド4体雇用（$7/日）で行動数を5倍にすれば圧勝できる。
- 変更: 新規実装。優先度付き todo 割当（水切れ危険 > 収穫 > 水やり > 植付 > 草むしり）、最近傍ターゲティング、毎ターン全量売却、種はオンデマンド購入。動物・肥料・土地は未使用。
- 結果: `records/eval_gen0001.json` — vs starter 勝率 100%（60戦、Wilson95 [0.94,1.0]、平均資金差 +$6,914）、vs random 100%、vs pass 100%。エラー/タイムアウト 0。1ターン平均 20µs・最悪 0.2ms（NFR-1余裕）。
- 判定: **昇格**（初代王者）。ゲート: starter≥95% ✓
- 学び:
  - starter の最終資金は ~$3.6k（+$600/シーズン程度）。全タイル化だけで ~$11.7k に到達。行動資源（ユニット数×24턴/日）が最初のボトルネックというのは正しい。
  - ハンド雇用はフィボナッチ初期が異常に安い（4体で$7/日 vs 生産増分 数百$/日）。Phase 1 では最適雇用数の損益分岐を要検証（5体目以降も$5,$8,...と安い）。
  - 毎ターン全量売却でも小麦/ニンジンは床値まで崩れない（小麦 log 吸収、ニンジンは sqrt で半値近くまで低下の観測余地あり）。売却タイミング最適化は Phase 1 の主要伸びしろ。
  - 次の候補: 土地購入（$1k → タイル25→50）、メロン導入（供給過少側で価格堅い）、動物系（ウール/ミルク高単価）。
