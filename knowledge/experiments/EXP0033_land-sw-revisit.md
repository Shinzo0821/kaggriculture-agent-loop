## 仮説

**gen0027（親 gen0026、SW を d11 に解禁）は 50 シードで `gate.pass = True` だった。**

| | gen0027（土地） | gen0031（出荷。実際に提出した） |
| --- | --- | --- |
| 全体マージン差 | **+$3,038 [+1,926, +4,150]** | +$538 [+358, +718] |
| 自分の最終資金 差 | **+$2,615 [+1,017, +4,212]** | −$116 [−341, +108] |
| 強帯マージン差 | +$1,049 **[−322, +2,420]** | +$717 [+473, +961] |
| rating Δ | 0.0 | 0.0 |

gen0027 を非昇格にしたのは**強帯 CI が 0 をまたいだ**から。点推定は **+$1,049 で正**である。
「強帯資金が動かない改善は前進と数えない」（`ops/NIGHTLY.md`）は gen0023（強帯 **−$2,347**）を
受けて書いた規則で、点推定が正の候補まで落とす意図だったかは確認が要る（→ `control/DIRECTIVES.md`）。

その後 gen0030/gen0031 が gen0026 の上に載ったので、**土地の効果が現王者の上でも残るか**を測り直す。

## 変更
