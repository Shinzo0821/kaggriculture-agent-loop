# EXP0014: プレミアム品の常時トリクル化（MILK/WOOL）

- 日付: 2026-09-04 ／ 世代: gen0014（親: gen0013）
- 仮説: 王者 gen0013 はプレミアム品(MILK/WOOL)を `price>=floor` で**全量ダンプ**していた。これは高値＝市場在庫が薄い局面で自ら大量供給し価格を暴落させる自己矛盾に見えた。LB勝者 Lorenzo($160k, 2026-09-04分析)はイチゴを町吸収量以下のペースで売り価格を128→267に**上げ続けた**。MILK base$160/WOOL base$200 も同じ吸収構造なので、全量パスを撤去し常時 `town_absorb/日` のトリクルに統一すれば、値上がり局面の売却単価が上がり日次収入が伸びるはず。
- 変更: `SELL_FLOORS` 分岐の全量ダンプ条件から `prices.get(item,0) >= floor` を除去（単一変数）。全量ダンプは `day>=DUMP_DAY`(換金期限) と `shed_pressure>=SHED_DUMP`(overflow回避) の破滅回避時のみに限定。`budget = max(trickle, I0+SLACK−minv)` が市場在庫の薄い局面で売却枠を自動拡大するため、値上がり局面でも売り逃しはしない（自己制動付き）という前提。メロンスプリント・hands7・SCALE_HANDS=8 は不変。
- 結果（100シード=対戦相手ごと200戦、78秒、エラー0）:
  - vs starter: **100%**（Wilson[0.981, 1.0]）、平均 **+$65,827**（gen0013 の +$65.7k とほぼ同値＝starter相手では差が出ない）
  - vs 王者 gen0013: **32.0%**（Wilson[0.259, 0.388]）、平均 **−$443.7**
  - 提出ゲート: 通過（エラー0・starter100%・王者32%≥30%）。昇格ゲート: 未達（32%<55%）。
- 判定: **棄却**（王者に純負・絶対資金増なし → 提出せず）
- 学び:
  1. **MILK/WOOL では「高値で全量ダンプ（=売り抜け）」が正しい**。Lorenzo のイチゴ「吸収量以下で売り価格を上げ続ける」戦略は MILK/WOOL に**転移しない**。理由の推定: (a) 我々の動物中核はミルク/毛糸の産出が町吸収レートを下回りがちで、そもそも在庫が薄く「暴落させるほどの供給」をしていない＝全量ダンプでも価格は崩れていなかった。(b) `budget=I0+SLACK−minv` のトリクル上限が高値(minv≈I0)局面で小さくなり、価格が高いのに売れず終盤 DUMP に持ち越して結局安く売る、という取りこぼしが発生。high-price を掴んだら即全量換金する方が期待値が高い。
  2. **Lorenzo の需要適応は「作付け品(イチゴ)を店舗吸収に合わせて増やす」話であって、既存動物産物の売却ペーシングの話ではない**。次に活かすなら Track B の「需要適応イチゴ作付け（店舗≥3のとき+労働増）」で吸収レート自体を作る側の実験にすべき。売却ロジック側(Track A)は現行 gen0013 が既に最適に近い。
  3. Track A（王者の経済効率改善）の余地は「売却ペーシング」ではなく「増員先の使い方（肥料自家使用・限界価値ベースの動物/店舗適応）」に残っている。売却タイミングはこのEXPで一旦底を打った。
