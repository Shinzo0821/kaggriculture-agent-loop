# EXP0018: 飼料小麦 d28 往復ビンタの除去

- 日付: 2026-09-04 ／ 世代: gen0018（親: gen0013、Track A）
- 仮説: cycle6 敗戦分析が指摘した「飼料小麦ネット漏れ −$6-8k/戦」の原因を計測で特定し、単一レバーで潰せば純効率改善で局所資金増が出る。

## 計測（gen0013、vs gen0010、10シード）

- 買い 290個/$13,327 ・ 売り 101個/$5,454 ・ **純資金 −$7,873/戦**（LB 分析の −$6-8k と一致）。給餌 255回/戦・自給小麦 ~73個。
- **漏れの局在**: 買いイベントを日別に見ると往復は **day28 に集中**。他23の買い日は各1回だが、
  **d28 だけ 10個×最大8回=80個（全買いの12-27%）を買っては全ダンプ**していた（seed 別 30-80個）。
- 機序: `day>=DUMP_DAY(28)` は shed_wheat を毎ターン全量売却する一方、`day<=LAST_FEED_DAY(28)` の
  給餌補充が `stock<頭数` で毎ターン買い直す → 「買→全ダンプ→買」ループ。

## 変更（gen0013 との唯一の差分）

市場売却の WHEAT ダンプ条件のみ:
```
if day >= FINAL_DAY(29):  n = shed_wheat            # 最終日だけ全量ダンプ
else:                     n = shed_wheat - feed_buffer  # DUMP_DAY も飼料バッファ(3n+2)を残す
```
バッファを残すと `stock>=3n+2>頭数` になり d28 の買いも自動停止 → 往復消滅。

## 結果

- **往復除去を確認**（gen0018、10シード）: 買い 290→**224個**（−66）、売り 101→**18個**、d28 買い 30-80→**0-10個**、
  給餌 255回で不変（餓えなし）、買い単価 $45.9→**$43.3**。
- **ただし局所最終資金はほぼ横ばい**: gen0013 $51,267 → gen0018 $51,343（+$76/10seed, vs gen0010）。
  往復は「買値 ≈ 売値」で**局所ではほぼ資金中立**だった（対戦相手 gen0010 が小麦を売買せず市場衝突が小さいため）。
- **評価（100シード, 400戦, エラー0）**: **vs gen0013 65.5%** [Wilson 58.7, 71.7]・平均 +$153.7 ／ vs starter 100%・+$65,751。
  提出ゲート pass（starter≥95 ✓ / champion>55 ✓）。**昇格ゲート(>55%)通過**（Wilson 下限 58.7%>55）。

## 判定: **昇格**（局所王者 gen0013 → gen0018）／提出（Track A）

- ミラー対戦（差分は d28 小麦ロジックのみ）では往復除去の小さな一貫した優位（+$150）が
  拮抗ゲームの過半（65.5%）を勝ちに倒す。純粋な正しさ改善で下振れ無し。

## 学び（ゲーム構造への還元）

1. **飼料小麦の「漏れ」は局所では資金中立**。買値≈売値のため往復自体は現金を溶かさない。
   cycle6 分析の LB −$6-8k は**「相手が小麦を自給して買わない」構造差**であって、
   売買タイミングのスプレッド損ではない。→ 真の対策は「自給小麦の増産（労働配分）or 頭数削減」であり、
   買い/売りタイミングの微調整では埋まらない（本 EXP がこれを反証した）。
2. **DUMP_DAY と LAST_FEED_DAY を同日(28)にすると自己往復が起きる**設計上の罠。
   ダンプ日は「バッファを残して余剰だけ処分」、全量清算は最終日に限定すべき。他の給餌品目でも同型注意。
3. **ミラー H2H は微小効率差の増幅器**。money 差 $153 でも勝率 65.5% に出る。純効率レバーの検定に有効。
4. 局所資金増は出なかったが、**LB では相手も d28 前後に小麦を売買する** → 自分の買い過ぎ/自ダンプで
   価格を歪めなくなる分、対人では neutral〜微正の見込み。下振れ無しの低リスク提出として Track A に採用。
