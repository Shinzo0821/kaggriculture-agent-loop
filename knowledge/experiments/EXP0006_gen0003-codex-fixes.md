# EXP0006: gen0003 の Codex 修正版（Track A・真のトリクル売り）

- 日付: 2026-08-31 ／ 世代: gen0006（親: gen0003）
- 仮説: gen0003 の下振れ改善は購入キャップ単独の効果で、プレミアム品売却の「ペーシング」は
  実質デッドコードだった（提出後 Codex 指摘）。価格が床値を割る時点で市場在庫は既に
  I0+30 超なので `budget = I0+GLUT_SLACK − minv ≤ 0`、つまり床未満では売却量ゼロ →
  保留 → shed 逼迫で全量ダンプ($1床)、という gen0002 と同じ悪循環に落ちていた。
  町の日次吸収レートを下限にした**真のトリクル売り**にし、$1床では保留、構造物の空き
  確認を購入条件に入れ、shed 逼迫判定に当日流入を織り込めば、床未満グラットでの下振れが
  上がり H2H が伸びる。
- 変更:
  - **fix1（本命）**: プレミアム品(MILK/WOOL)売却を真のトリクル売りに。床未満域の予算を
    `max(町吸収レート, I0+GLUT_SLACK − minv)` にした。町吸収レート = 町センター1/日 +
    ミルク店6/日 + 毛糸店(単品)12/日（`premium_absorb`）。これは demand_caps の増頭ペースと
    釣り合うので売る量が価格をほぼ動かさない。**価格が$1床に張り付いている時は保留**
    （町の吸収で在庫が抜け価格が戻るのを待つ＝トリクルすると在庫横ばいで$1に固定されるため）。
  - **fix2**: `next_buy` を「今日中に家を確保できる種」に限定（空き構造物 or 所有動物の
    住宅を満たした後に残る空きタイル）。空き構造物のある種は先行建設しない → 誤種別の
    先行建設で最後の空きタイルを潰し、後買い動物がシェッドに恒久滞留する事故を防止。
  - **fix3**: shed 全量ダンプ判定を `shed_total + 手持ち在庫`（当夜ドロップされる流入）で行う。
- 結果: `records/eval_gen0006.json`（30シード×両側=各60戦、steps720、エラー0）
  - vs **starter 100%**（CI[0.94,1.00]、平均 +$60,329）
  - vs **gen0003（親）78.3%**（CI[0.66,0.87]、平均 +$485）← **修正が親を明確に上回る**
  - vs **gen0002（王者）53.3%**（CI[0.41,0.65]、平均 +$1,982）← gen0003 の 51.7% から改善
- 判定: **提出ゲート通過**（エラー0・starter100%≥95%・王者53.3%≥30%）。
  **昇格ゲート未達**（王者53.3% < 55%、CI が 0.5 を跨ぐので統計的にも王者と非有意）→ 王者交代なし。
  gen0002 は名目上の局所王者のまま。ただし gen0006 は**保有全世代で H2H 最強**
  （gen0003 を 78%、gen0002 を 53% で上回る）で、現 LB 首位 gen0003(569.9) を直接叩ける。
- 学び:
  - **床未満グラットは「保留 or 全量ダンプ」の二択が悪手**。町の吸収レートに合わせた
    トリクル売りが正解。gen0003 の下振れ改善は購入キャップ由来で、売却側は未着手だった。
    町吸収レートは demand_caps（増頭）と対称な量なので、生産・売却の両輪を同じ指標
    （unlocked_shops）で駆動できるのが構造的にきれい。
  - **$1床では逆にトリクルしてはいけない**。売れば在庫横ばいで価格が$1に固定される。
    保留して町の吸収に在庫を抜かせ価格を戻すのが正着（終盤 DUMP_DAY と overflow 弁で担保）。
  - H2H では gen0006 が明確に最強だが、**昇格ゲート(vs gen0002 55%)は僅かに届かない**。
    gen0002 は「動物過密に強い受動型」で相性が特殊。LB では動物型の相手が多いので、
    gen0003 を 78% で叩ける gen0006 の方が実プールでの期待値は高い読み。→ 次UTC日の
    **Track A 最優先提出候補**（gen0005 lean melon = Track B と対で出す）。
  - 次の候補: (a) gen0006 の LB 実測（gen0003 569.9 を超えるか）、(b) Track B メロン/土地の
    続き、(c) 限界価値ベースの購入・肥料の自家使用。
