# EXP0020: 上位型の丸ごと実装（gen0020）と over-reinvestment 破綻の発見

- 日付: 2026-09-05 ／ 世代: gen0020（親: gen0018）
- 仮説: LB上位の日次骨格（土地2枚 d6/d10・メロンIPO d10で再投資・牛羊拡張・イチゴ2波・小麦自給）を丸ごと実装すれば gen0018 の $52k を大きく超え強帯（$80k+）に届く。
- 変更: gen0018 の機構（ユニット最近傍割当・市場売却の床/トリクル・給餌日課）の上に、3クアドラント拡張スケジュール（NE d6 / SW d10）、メロン2波（d0×8 → d10 IPO → 2波12）、イチゴ2波（早出し2 / d8×9 / d10×16）、小麦自給+終盤ブロック、cow_target 0→8・hands 5→14 を新規実装。

## 結果（破滅級。昇格・提出とも不可）

- スモーク vs gen0018: seed42 = **$11,058**（相手 $68,586）／ seed7 = **$2,586**（相手 $74,198）。profile max 0.012s（1秒制約 OK）。
- リプレイ実測（seed42, player0=gen0020）の資金曲線: d2〜d18 まで **$20 に貼り付き**、d19 で $440、最終 d29 で $10,054。gen0018 は同シードで $68k。

## 根本原因（リプレイ実測で確定）: over-reinvestment without survival reserve

失敗の連鎖:

1. **メロンIPO は正常に発火**。d0 に植えた 8 タイル（実際 7 タイル生存、1タイルは d1 に無水で雑草化）が age10=d10 に yield 5 まで育ち、d10 に全収穫（~35 個）。ここまでは設計通り。
2. **proceeds を全額 追加拡張に即投入**。d10 の同ターンで SW 土地（$2,000）＋2波メロン種＋2波イチゴ種＋動物を10頭へ＋hands を14へ。結果 **現金 buffer が $20 に激減**。
3. **feed 小麦が買えず、小麦自給も不足** → d12 に 10 頭（COW6 SHEEP4）いた動物が、慢性的な unfed（h12 で unfed 8-9）を経て **d14 に 3 頭（COW2 SHEEP1）へ escape**（README:111 「2日給餌なしで動物は逃走・回復不能」）。milk/wool エンジンが消滅。
4. 3クアドラントに広げた作物も、$20 buffer と不足 labor では水やり・収穫が回らず雑草化。以後 $20 台のまま推移し、終盤の小麦ブロックだけで $10k まで戻すのが精一杯。

- 判定: **棄却（FAILED / 非昇格 / 非提出）**。gen0018（1クアドラント持続で $52k）に $40k+ 負け。

## 学び（ゲーム構造への還元。次世代の設計制約）

1. **拡張は「メロンIPOで得た現金の使い道」ではなく「labor と feed が支えられる資産量」で決まる。** 上位型の 3クアドラント・10頭は、それを維持できる hands と小麦供給が前提。gen0020 は資産だけ先に増やして維持力が伴わず、増やした端から死んだ。**over-reinvestment（現金 buffer を0にする再投資）は破滅級。**
2. **動物 escape はスコアの最大の毀損**。milk/wool は主要収入。feed 小麦（自給＋市場買い）を切らさないことが、拡張のどの要素よりも優先。**動物数は「確実に feed できる数」に上限を張るべき**（現金リザーブ＋小麦在庫で動的に）。
3. **メロンIPO proceeds の一部は運転資金として保持すべき**（全額再投資しない）。上位リプレイでも d10 現金を 0 近くまで落とすが、それは feed/水やりを回すだけの hands と小麦が既にある前提。維持力のない世代が同じ再投資をすると starvation に直行する。
4. **cycle1 の Analyst 実測（`knowledge/analysis/2026-09-05_top-winner-vs-loser.md`）と実装がズレている**: 実装は scout §2 の棄却済み骨格（1牛4羊寄り・メロン8・hands14・d3分岐なし）に基づく。実測仕様（d0=2牛2羊・メロン12・hands上限12・d3第1店で牛羊分岐）は未反映。ただし本 EXP の破綻はこのズレ以前の「維持力欠如」が主因。

## 次の一手（cycle2 で試験 → 後続に引き継ぐ）

- 拡張を labor/feed が支えられる水準に抑える最小改造を試す: (a) 土地は 2 枚まで（SW を買わない）、(b) 全 discretionary buy（土地・動物・種）に現金リザーブ $R を課し、メロン proceeds を運転資金として残す。これで動物 escape が止まり資金曲線が立ち上がるかを 12 シードで測定。
- 効けば「持続可能な 2 クアドラント」を新王者候補に。効かなければ Strategist を呼び、上位型が 3 クアドラントを維持できる keystone（feed 自給の回し方・hands 配分）を上位リプレイと突き合わせる。
