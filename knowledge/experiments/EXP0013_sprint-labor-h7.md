# EXP0013: スプリント + 労働装備 TARGET_HANDS=7（昇格・過去最大のH2Hジャンプ）
- 日付: 2026-09-04 ／ 世代: gen0013（親: gen0012）
- 仮説: EXP0012 でメロンスプリントの労働律速が確定（メロン粗利を中核出力の低下が相殺）。hand は fib×$1/日でほぼ無料なので、メロン7タイルぶんの仕事に対して序盤から増員すれば粗利がそのまま net になる。「増員は8人で頂点」（EXP0010/11）は農場が小さく仕事が無かっただけ。
- 変更: TARGET_HANDS 4→7（gen0012 との唯一の差分。scaling 時 SCALE_HANDS=8 不変）。事前アブレーション（10シード、sum diff vs gen0010）: h5=+3,449 / h6=+15,998 / **h7=+23,153** / h8=+11,175 → 7 が頂点。
- 結果: vs starter 100%（Wilson [98.1, 100]、平均 **+$65,725** = gen0010 比 +$5,058 の絶対資金増）/ **vs 王者 gen0010 89.5%**（200戦、Wilson [84.5, 93.0]、平均 **+$2,524**）。400戦エラー0。
- 判定: **昇格（王者交代 gen0010→gen0013）**。過去最大の H2H ジャンプ（gen0010 の 75% を上回る 89.5%）。
- 学び: **「労働と仕事はセットで増やす」がこのゲームの中核原理。** 労働だけ増やす（EXP0011 h9=35%）も、仕事だけ増やす（EXP0012 +$22）も単体では無効/中立で、両方同時（本世代）で +$2.5k/戦。過去の「作付け拡張は純負」（トマトEXP0009・メロンEXP0004/5/7）は全て労働固定のまま仕事を増やした実験だった — 棄却済み系統も「労働を装備して」再検証する価値がある（次: イチゴ需要適応、Lorenzo は イチゴ$67.4k）。h8 で反転（+11.2k）するのは初期資金$3000 の給餌・種・動物購入との資金競合と推測（未検証）。
